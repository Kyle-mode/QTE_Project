# QTE Training Game

A C# Windows Forms quick-time-event (QTE) training game built around time-sensitive user input and visual feedback.

## Highlights

- Runs an event-driven interaction loop with a 20 ms timer.
- Rotates an on-screen indicator through randomized target arcs.
- Evaluates Space-key input timing and maintains combo scoring.
- Tracks repair progress, adapts game speed, and records completion time with `Stopwatch`.

## Tech Stack

C#, .NET Windows Forms

## Run Locally

1. Open `QTE_Project.sln` in Visual Studio.
2. Build and run the Windows Forms project.

## Project Context

Built as a desktop-game project to practice event-driven UI programming, timing logic, and stateful interaction design.
